- (decision) Direção visual: dark-first, painel de instrumentos calmo; cyan para interação, âmbar para warning/incidente, verde para saudável, vermelho para erro/destrutivo; sem gradientes decorativos.
- (decision) Tipografia: Geist/Inter para UI, JetBrains Mono para queries, IDs e logs; escala 12/13/14/16/20/28; 4px spacing grid; rounded 6/10.
- (decision) Desktop-first: >=1280 full, 1024-1279 compact, 768-1023 read-only, <768 read-only mobile fora do v1.
- (decision) IA: Overview, Explore, Dashboards, Services, Alerts, Incidents, Settings; command palette global; URL state para tempo/filtros.
- (decision) Interação keyboard-first: Cmd/Ctrl+K command palette, / busca, g+letra navegação, [ ] tempo, Esc fecha, ? atalhos; nada hover-only.
- (decision) Acessibilidade: WCAG 2.2 AA, foco visível, tabela alternativa para gráficos, estado nunca só por cor, reduced motion.
- (decision) Voz: direta, calma, técnica; sem exclamações, sem antropomorfismo, sem 'oops'; erros dizem o que aconteceu e o próximo passo.
